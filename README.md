# Ames House Price Regression

Учебный ML-проект по прогнозированию стоимости домов. Основная метрика -
MAE, поскольку она показывает среднюю абсолютную ошибку прогноза
в денежных единицах.

## Данные

Использован датасет Ames Housing из OpenML:

- 1460 домов;
- 80 признаков;
- числовые и категориальные данные;
- пропуски в 19 признаках;
- целевая переменная - `SalePrice`.

Данные разделены на train и test в пропорции 80/20. Тестовая выборка
не использовалась при выборе модели и настройке параметров.

## Подготовка данных

Обработка реализована внутри `Pipeline`, чтобы избежать утечки данных:

- пропуски числовых признаков заполнены медианой;
- числовые признаки стандартизированы;
- пропуски категориальных признаков заполнены наиболее частым значением;
- категории преобразованы с помощью `OneHotEncoder`;
- технический признак `Id` исключён.

## Модели

С помощью 5-кратной кросс-валидации сравнены:

- DummyRegressor;
- Ridge;
- Ridge с логарифмированием целевой переменной;
- Random Forest;
- Gradient Boosting.

Итоговая модель - `GradientBoostingRegressor` с функцией потерь Huber:

- `n_estimators=500`;
- `learning_rate=0.03`;
- `max_depth=2`;
- `min_samples_leaf=3`.

## Результаты

| Метрика | Результат |
|---|---:|
| CV MAE | 16 276 |
| Test MAE | 17 271 |
| Test RMSE | 30 503 |
| Test R² | 0.879 |
| Улучшение MAE относительно baseline | 71% |

Близкие значения CV и test свидетельствуют о нормальном переносе
модели на ранее не использованные данные.

## Анализ ошибок

На тестовой выборке модель хуже работает в верхнем ценовом квартиле:
MAE дорогих домов составляет 34 077 против 10-13 тысяч в средних
ценовых сегментах. Модель склонна переоценивать дешёвые и
недооценивать дорогие дома.
